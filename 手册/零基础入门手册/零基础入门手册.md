## 1. 编程到底是什么

**编程，就是给电脑写一份「步骤清单」。**

电脑很笨：它不会自己想事情，但它很快、很听话。

举个例子，你让同学帮你买水，说「帮我去买水」，他可能买错牌子、买错温度。
但如果你写清楚：

```
1. 出门右转走 100 米
2. 进「小卖部」
3. 拿一瓶 500ml 的矿泉水
4. 去收银台付 2 元
5. 回来交给我
```

他就能一字不差地做对。

**程序就是写给电脑的这份清单**，只不过用的是电脑能看懂的「语言」，叫程序语言。

我们学的是 **Java**（读作「加哇」），世界上很多软件、安卓 App、银行系统都用它。

## 2. 电脑是怎么运行你写的程序的

你写的代码，电脑看不懂。要先「翻译」。

```
你写的中文草稿       翻译          电脑执行的版本
Hello.java    →    javac    →    Hello.class    →    java    →    屏幕上出现文字
```

- `.java` 文件：你写的代码（人能看懂的）
- `javac`：翻译官，把代码翻译成电脑能执行的版本
- `.class` 文件：翻译完的结果（电脑看懂的）
- `java`：播放器，让翻译好的程序跑起来

就像写作文：先写中文稿（.java），再翻译成英文稿（.class），最后朗读出来（运行）。

## 3. 第一次动手：让电脑说句话

### 3.1 装好工具（只装一次）

1. 打开浏览器，搜索「JDK 17 下载」，进官网（oracle.com 或 adoptium.net）；
2. 下载 Windows 版本，一路「下一步」安装；
3. 装完后，按 `Win + R`，输入 `cmd`，回车，打开黑色窗口；
4. 输入：

```bash
java -version
```

如果出现类似 `java version "17.0.x"`，就成功了。

### 3.2 写第一个程序

1. 在 `D 盘` 新建文件夹 `code`；
2. 用记事本（或 VS Code）新建文件，**文件名必须叫 `Hello.java`**；
3. 把下面内容一字不差地抄进去：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("你好，我是学弟");
    }
}
```

### 3.3 运行

在黑色窗口里输入：

```bash
cd D:\code
javac Hello.java
java Hello
```

屏幕上出现：

```
你好，我是学弟
```

**恭喜，你已经写出第一个程序了。**

### 3.4 三条最容易踩的规则

| 规则 | 说明 |
| --- | --- |
| 文件名必须是 `Hello.java` | 因为代码里写的是 `class Hello`，两个名字必须一样 |
| 每句后面要有分号 `;` | 中文分号不行，必须是英文的 `;` |
| 运行时写 `Hello`，不加 `.java` | `java Hello` 不是 `java Hello.java` |

改一改：把「你好，我是学弟」改成你自己的名字，重新 `javac` + `java` 看看。

### 3.5 更省事的办法：用 Eclipse（推荐初学者）

如果觉得「记事本 + 黑色窗口」太麻烦，可以用 **Eclipse**——一个专门写 Java 的软件，装一次以后，写代码、运行都在一个窗口里点鼠标就行。

#### 下载和打开

1. 先装好 JDK（3.1 那一步已经装了）；
2. 打开 <https://www.eclipse.org/downloads/>，下载 **Eclipse IDE for Java Developers**；
3. 下载下来是个 zip，解压到 `D:\eclipse`（不用安装）；
4. 双击里面的 `eclipse.exe`；
5. 第一次打开会让你选 **workspace**（代码存放的文件夹），填 `D:\eclipse-workspace`，点 Launch。

#### 新建项目和类

1. 菜单 **File → New → Java Project**；
2. Project name 填 `HelloProject`，点 **Finish**；
3. 左边展开 `HelloProject` → 右键 `src` → **New → Class**；
4. Name 填 `Hello`，勾选 `public static void main(String[] args)`，点 **Finish**；
5. 右边会出现自动生成的代码：

```java
public class Hello {
    public static void main(String[] args) {
        // 光标在这里
    }
}
```

#### 写代码、运行

在 `main` 的两个大括号中间，写这一行：

```java
System.out.println("你好，我是学弟");
```

按 `Ctrl + S` 保存，然后点顶上绿色的三角形 ▶（或右键文件 → **Run As → Java Application**）。

下方的 **Console** 窗口会显示：

```
你好，我是学弟
```

**Eclipse 里不用手动敲 `javac`，点一下 ▶ 就编译加运行了。**

#### Eclipse 的常见问题

| 问题 | 解决 |
| --- | --- |
| 中文打印出来是乱码 | **Window → Preferences → General → Workspace → Text file encoding**，选 `UTF-8` |
| 左边看不到项目 | 右键项目 → **Refresh** |
| 点了 ▶ 没反应 | 确认代码已保存（`Ctrl + S`），窗口标题没有 `*` |
| 想换个文件夹存代码 | **File → Switch Workspace** |
| 找不到 `src` 文件夹 | 项目没建对，重新 File → New → Java Project |

#### 两种方式怎么选

| | 记事本 + 命令行 | Eclipse |
| --- | --- | --- |
| 要装什么 | 只装 JDK | JDK + Eclipse |
| 写代码 | 没有提示，全靠自己 | 有自动补全、报错提示 |
| 运行 | 敲 `javac`、`java` | 点一下 ▶ |
| 适合 | 想搞懂程序到底怎么跑 | 想快点做出东西 |

**建议**：先用记事本跑通一次（知道 `.java` 怎么变成能运行的程序），之后日常用 Eclipse，省下的时间用来想逻辑。

## 4. 变量：给数据起个名字

**变量就是一个盒子，里面放数据，盒子上贴个名字。**

```java
int age = 13;                 // 整数盒子，叫 age，里面放 13
String name = "小明";          // 文字盒子，叫 name，里面放"小明"
double score = 95.5;          // 小数盒子，叫 score，里面放 95.5
boolean pass = true;          // 对错盒子，只能放 true 或 false
```

打印出来看看：

```java
public class Demo {
    public static void main(String[] args) {
        int age = 13;
        String name = "小明";

        System.out.println(name);
        System.out.println(age);
        System.out.println("我叫" + name + "，今年" + age + "岁");
    }
}
```

运行结果：

```
小明
13
我叫小明，今年13岁
```

### 四种最常见的盒子

| 类型 | 放什么 | 例子 |
| --- | --- | --- |
| `int` | 整数 | `int n = 10;` |
| `double` | 小数 | `double t = 26.5;` |
| `String` | 文字（要用双引号） | `String s = "你好";` |
| `boolean` | 真 / 假 | `boolean ok = true;` |

**注意**：盒子有类型，`int` 盒子里不能放「小明」。

**小任务**：定义你的年龄、身高、名字，用一句话打印出来。

## 5. 让程序算数学题

```java
public class MathDemo {
    public static void main(String[] args) {
        int a = 7;
        int b = 2;

        System.out.println(a + b);      // 9
        System.out.println(a - b);      // 5
        System.out.println(a * b);      // 14
        System.out.println(a / b);      // 3（注意！不是 3.5）
        System.out.println(a % b);      // 1（余数）
    }
}
```

**大坑**：两个整数相除，结果还是整数，小数部分直接扔掉。

```java
System.out.println(7 / 2);        // 3
System.out.println(7.0 / 2);      // 3.5
```

想要小数，就让其中一个数带小数。

**小任务**：算一下「语文 88 分、数学 95 分、英语 92 分」的平均分，打印出来。

## 6. 让程序做判断

```java
public class IfDemo {
    public static void main(String[] args) {
        int score = 85;

        if (score >= 90) {
            System.out.println("优秀");
        } else if (score >= 60) {
            System.out.println("及格");
        } else {
            System.out.println("不及格");
        }
    }
}
```

读法：**如果**（条件）**就**（做事），**否则如果**……**否则**……

比较用的符号：

| 符号 | 意思 |
| --- | --- |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |
| `==` | 等于（**两个等号**） |
| `!=` | 不等于 |

**最常见的错**：判断相等写成 `=`（一个等号是赋值，两个才是比较）。

```java
if (score == 100) { ... }      // 对
if (score = 100) { ... }       // 错，编译不过
```

**小任务**：改成自己的分数，看看打印什么。

## 7. 让程序重复做事

如果想让电脑数 1 到 10，不用写 10 行，用循环：

```java
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}
```

读法：**i 从 1 开始，只要 i 小于等于 10，就做下面的事，做完 i 加 1**。

再看一个「从 1 加到 100」：

```java
public class SumDemo {
    public static void main(String[] args) {
        int sum = 0;
        for (int i = 1; i <= 100; i++) {
            sum = sum + i;
        }
        System.out.println("1 到 100 的和是：" + sum);
    }
}
```

结果：

```
1 到 100 的和是：5050
```

`while` 是另一种循环，意思是「只要条件成立就一直做」：

```java
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
```

**小任务**：打印 1 到 20 里所有的偶数。

## 8. 让程序听你说话

前面都是程序自己说，现在让程序能「问你问题」。

```java
import java.util.Scanner;

public class AskDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("你叫什么名字？");
        String name = sc.nextLine();

        System.out.print("你今年几岁？");
        int age = sc.nextInt();

        System.out.println("你好，" + name + "，你今年 " + age + " 岁。");
    }
}
```

运行后，光标会等你打字，输入完按回车。

| 方法 | 读什么 |
| --- | --- |
| `sc.nextLine()` | 读一整行文字 |
| `sc.nextInt()` | 读一个整数 |
| `sc.nextDouble()` | 读一个小数 |

**注意**：先 `nextInt()` 再 `nextLine()`，可能会读到空行，这是 Java 的一个老毛病，遇到时在中间多写一句 `sc.nextLine();` 吃掉回车就行。

## 9. 把代码打包成积木

有些代码反复用，就把它打包成一个「积木」，起个名字，用的时候喊它。

```java
public class MethodDemo {
    public static void main(String[] args) {
        sayHello();
        int result = add(3, 5);
        System.out.println("3 + 5 = " + result);
    }

    // 不返回结果的积木
    static void sayHello() {
        System.out.println("你好！");
    }

    // 会返回结果的积木：投进去两个数，吐出一个结果
    static int add(int a, int b) {
        return a + b;
    }
}
```

两个比喻：

- `void` 的积木：像喇叭，喊一声就完事，不给你东西；
- `int` / `double` 的积木：像自动售货机，投币（参数）进去，掉出饮料（返回值）。

**小任务**：写一个方法，输入三个分数，返回平均分。

## 10. 动手做：猜数字游戏

现在把前面学的全部用上，做一个游戏：

> 电脑心里想一个 1~100 的数字，你来猜。
> 猜大了它说「大了」，猜小了说「小了」，猜中为止。

```java
import java.util.Random;
import java.util.Scanner;

public class GuessGame {
    public static void main(String[] args) {
        // 1. 电脑随机想一个 1~100 的数
        Random random = new Random();
        int secret = random.nextInt(100) + 1;   // nextInt(100) 是 0~99，加 1 变成 1~100

        // 2. 准备接收输入
        Scanner sc = new Scanner(System.in);

        int count = 0;          // 猜了几次

        System.out.println("我想好了一个 1~100 的数字，你猜猜看！");

        // 3. 一直猜，直到猜中
        while (true) {
            System.out.print("请输入你猜的数字：");
            int guess = sc.nextInt();
            count = count + 1;

            if (guess > secret) {
                System.out.println("大了");
            } else if (guess < secret) {
                System.out.println("小了");
            } else {
                System.out.println("猜中了！你一共猜了 " + count + " 次。");
                break;          // 跳出循环，游戏结束
            }
        }
    }
}
```

### 这个程序在干什么

| 代码 | 意思 |
| --- | --- |
| `new Random()` | 叫来一个「随机数生成器」 |
| `random.nextInt(100) + 1` | 生成 1~100 的随机整数 |
| `new Scanner(System.in)` | 叫来一个「读键盘」的工具 |
| `while (true)` | 一直循环，直到 `break` |
| `if (guess > secret)` | 猜大了 |
| `break` | 跳出循环 |

### 自己改一改

1. **限制次数**：只给 7 次机会，用完就提示「答案是 xx」；
2. **记录最佳成绩**：猜中后显示「你比上次少用了 2 次」；
3. **改范围**：把 100 改成 1000。

**自己能改出来，就说明你真的会了。**

## 11. 报错了怎么办

报错不是骂你，是电脑在说「这里有句话我没看懂」。

**看报错的最后一行**，它一般写着原因，比如：

| 报错 | 意思 | 怎么改 |
| --- | --- | --- |
| `';' expected` | 少了分号 | 找到那一行补上 `;` |
| `class Hello is public, should be declared in a file named Hello.java` | 文件名和类名不一样 | 把文件名改成 `Hello.java` |
| `cannot find symbol` | 有个词电脑不认识 | 拼写错了，或没定义这个变量 |
| `reached end of file while parsing` | 大括号 `{}` 没配对 | 检查 `{` 和 `}` 数量一样多 |
| `NumberFormatException` | 想转数字，但内容不是数字 | 输入时别输字母 |

还有三个「不是报错但没反应」的情况：

1. 忘了 `javac` 编译，直接 `java`；
2. 代码没保存就编译了（记事本要按 `Ctrl + S`）；
3. 运行的是旧文件，重新 `javac` 一次。

**心态**：写程序 90% 的时间都在和报错打交道，这不丢人，改对了就是进步。

## 13. 常用代码小抄

```java
// 打印
System.out.println("文字");

// 变量
int a = 10;
double b = 3.14;
String s = "文字";
boolean ok = true;

// 输入
import java.util.Scanner;
Scanner sc = new Scanner(System.in);
int n = sc.nextInt();
String line = sc.nextLine();

// 判断
if (a > 10) {
    // ...
} else if (a > 5) {
    // ...
} else {
    // ...
}

// 循环
for (int i = 1; i <= 10; i++) {
    // ...
}

while (a < 100) {
    a = a + 1;
}

// 随机数
import java.util.Random;
Random r = new Random();
int x = r.nextInt(100);       // 0~99

// 方法
static int add(int x, int y) {
    return x + y;
}

// 整个程序的外壳（每个程序都要有）
public class 文件名 {
    public static void main(String[] args) {
        // 你的代码
    }
}
```

最后一句：**能跑起来的第一行代码，就是最好的开始。**

## 附：代码与注释对照表

| 你想做什么 | 代码 | 参数说明 |
| --- | --- | --- |
| 打印一行字 | `System.out.println("文字");` | 括号里放要打印的内容，文字要加双引号 |
| 定义整数 | `int age = 13;` | `int`：整数类型；`age`：名字；`13`：值 |
| 定义小数 | `double score = 95.5;` | `double`：小数类型 |
| 定义文字 | `String name = "小明";` | `String`：文字类型，值必须加双引号 |
| 定义真假 | `boolean ok = true;` | 只能放 `true` 或 `false` |
| 准备读键盘 | `Scanner sc = new Scanner(System.in);` | `System.in`：表示键盘输入 |
| 读一整行 | `String line = sc.nextLine();` | 读到你按回车为止 |
| 读一个整数 | `int n = sc.nextInt();` | 输入不是整数会报错 |
| 判断 | `if (score >= 60) { } else { }` | `>=`：大于等于；`==`：等于（两个等号） |
| 循环 10 次 | `for (int i = 1; i <= 10; i++) { }` | `i=1`：起点；`i<=10`：条件；`i++`：每次加 1 |
| 条件循环 | `while (i <= 5) { i++; }` | 条件一直成立就会一直做，记得改 `i` |
| 定义方法 | `static int add(int a, int b) { return a + b; }` | `a`、`b`：参数；`return`：返回结果 |
| 调用方法 | `int r = add(3, 5);` | 括号里按顺序传参数 |
| 生成随机数 | `Random r = new Random(); int x = r.nextInt(100);` | `100`：上限，结果是 0~99 |
| 跳出整个循环 | `break;` | 立即结束循环 |
| 跳过本次 | `continue;` | 跳过这一轮，继续下一轮 |
