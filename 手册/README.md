## 三、给初一学弟的路线

```
第 1 步  零基础入门手册        （约 1 周，做完猜数字游戏）
   ↓
第 2 步  Java 基础语法使用手册  （约 2 周，把语法补齐）
   ↓
第 3 步  挑一个做界面：Swing 或 JavaFX
   ↓
第 4 步  按兴趣选：SQL / 网络 / 多线程 / IO
   ↓
随时    命名规则、Git 仓库（边写边翻）
```

### 每一步的「毕业标准」

| 步骤 | 能做到什么才算过关 |
| --- | --- |
| 第 1 步 | 能自己改猜数字游戏：限制次数、显示猜了几次 |
| 第 2 步 | 能看懂 `DbConfig`、`ConfigManager` 这类类，知道 `static`、`for`、`List` 是什么 |
| 第 3 步 | 能做出一个「有按钮、有表格、能刷新」的窗口 |
| 第 4 步 | 能做出「窗口 + 数据库」的完整小程序 |

## 四、三种格式怎么用

| 格式 | 适合 | 怎么打开 |
| --- | --- | --- |
| `.html` | 正常阅读（推荐） | 双击，默认用 Edge 打开；右上角可切深浅色 |
| `.md` | 要改内容时 | 用 VS Code 或记事本打开 |
| `.txt` | 手机、打印、没装浏览器 | 双击，记事本就能看 |

内容完全一样，选一个顺手的就行。

## 五、写代码用 Eclipse 还是记事本？

| | 记事本 + 命令行 | Eclipse |
| --- | --- | --- |
| 优点 | 知道程序到底怎么运行 | 自动补全、一键运行、报错提示 |
| 缺点 | 麻烦、没提示 | 要额外下载安装 |
| 建议 | 第一次跑通用它 | 之后都用它 |

Eclipse 的安装和新建项目步骤，写在《零基础入门手册》第 3.5 节。

## 六、三个学习建议

1. **每天 30 分钟，比周末突击 5 小时有用**；
2. **不要复制粘贴**，自己敲一遍，报错自己读；
3. **报错是电脑在提示你，不是骂你**——看最后一行，改了就进步。
