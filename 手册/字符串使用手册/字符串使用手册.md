## 1. String 到底是什么

`String` 是**字符序列**，但它不是基本类型，是一个**类**（`java.lang.String`）。

```java
String s = "EMS";
```

三个重要事实：

| 事实 | 说明 |
| --- | --- |
| 不可变 | 一旦创建，内容永远不能改，所有「修改」都是产生新对象 |
| 有常量池 | 字面量 `"EMS"` 会被缓存复用，相同字面量指向同一个对象 |
| `String` 是 `final` 类 | 不能被继承，保证不可变性 |

`String` 在 JDK 9 之后内部是 `byte[]` + 编码标记（以前是 `char[]`），这是为了省内存，对使用者透明。

## 2. 创建字符串与常量池

两种写法，行为不同：

```java
String a = "EMS";              // 字面量：先查常量池，有就复用
String b = "EMS";              // 复用同一个对象
String c = new String("EMS");  // new：一定创建新对象（在堆里）

System.out.println(a == b);    // true，同一个对象
System.out.println(a == c);    // false，c 是新对象
System.out.println(a.equals(c)); // true，内容相同
```

常量池（字符串池）的规则：

| 写法 | 是否进池 | 例子 |
| --- | --- | --- |
| 字面量 | 进 | `"abc"` |
| 字面量拼接的编译期常量 | 进 | `"ab" + "c"` 编译时合成 `"abc"` |
| `new String(...)` | 不进池（除非 `intern()`） | `new String("abc")` |
| 变量拼接、方法返回 | 不进池 | `s1 + s2` |

`intern()` 手动入池：

```java
String x = new String("EMS").intern();
System.out.println(x == "EMS");   // true
```

**结论**：日常比较内容一律用 `equals`，不要依赖 `==`，哪怕它有时候「碰巧」是 true。

## 3. 字符串为什么不可变

```java
String s = "hello";
s = s + " world";
```

第二行**没有改** `"hello"`，而是新建了一个 `"hello world"`，`s` 指向新对象。

不可变带来的好处：

| 好处 | 说明 |
| --- | --- |
| 安全 | 作为参数传给别人，不会被偷偷改掉 |
| 可共享 | 常量池复用，省内存 |
| 线程安全 | 多线程读同一个字符串不会出问题 |
| 可做 Map 的键 | 内容不变，哈希值不变，键不会「丢」 |

代价：**频繁修改会产生大量临时对象**，所以循环里拼接要用 `StringBuilder`（第 14 章）。

## 4. 长度、判空与判空白

```java
String s = "EMS";

s.length();        // 3，字符个数
s.isEmpty();       // false，长度是否为 0
s.isBlank();       // false，是否为空或全是空白（JDK 11+）

"".isEmpty();      // true
"   ".isBlank();   // true（全是空格）
"   ".isEmpty();   // false（长度是 3）
```

判空的正确写法：

```java
// 错：null 会抛 NullPointerException
if (s.isEmpty()) { }

// 对：先判 null
if (s == null || s.isEmpty()) { }

// 或者用工具
if (s == null || s.isBlank()) { }
```

`length()` 返回的是 `char` 的数量，中文一般是一个 `char`，但 emoji 是**两个** `char`（第 15 章）。

## 5. 比较：== 还是 equals

| 写法 | 比较什么 | 用不用 |
| --- | --- | --- |
| `a == b` | 是否指向同一个对象 | 不用来比较内容 |
| `a.equals(b)` | 内容是否相同（区分大小写） | 用 |
| `a.equalsIgnoreCase(b)` | 内容是否相同（忽略大小写） | 用 |
| `a.compareTo(b)` | 字典序，返回正/负/0 | 排序用 |
| `a.compareToIgnoreCase(b)` | 忽略大小写的字典序 | 排序用 |

```java
String a = "EMS";
String b = new String("EMS");

a == b;                    // false
a.equals(b);               // true
"ems".equalsIgnoreCase(a); // true

a.compareTo("ABC");        // 正数（E 在 A 后面）
"a".compareTo("b");        // -1
```

**最安全的写法**：把常量放前面，避免空指针：

```java
if ("EMS".equals(name)) { }      // name 为 null 也不报错
if (name.equals("EMS")) { }      // name 为 null 会 NPE
```

`equals` 是区分大小写的；`equalsIgnoreCase` 不区分；`compareTo` 返回差值，不要拿它当布尔用。

## 6. 查找与定位

```java
String s = "EMS-2026-01-01";

s.indexOf("2026");        // 4，第一次出现的位置
s.lastIndexOf("-");       // 12，最后一次出现
s.indexOf("x");           // -1，没找到
s.contains("2026");       // true，是否包含
s.startsWith("EMS");      // true
s.endsWith("01-01");      // true
s.charAt(0);              // 'E'，下标越界抛异常
```

要点：

- `indexOf` 找不到返回 **-1**，不是 0，也不是抛异常；
- `charAt` 下标从 0 开始，越界抛 `StringIndexOutOfBoundsException`；
- 判断「包含」用 `contains`，比 `indexOf(...) >= 0` 更清楚。

## 7. 截取、替换、大小写

```java
String s = "EMS-2026-01-01";

s.substring(4);           // "2026-01-01"，从下标 4 到结尾
s.substring(0, 3);        // "EMS"，含头不含尾（0、1、2）

s.replace("-", "/");      // "EMS/2026/01/01"，替换全部
s.replaceAll("-", "/");   // 同上，但参数是正则
s.replaceFirst("-", "/"); // 只替换第一个

s.toUpperCase();          // "EMS-2026-01-01"
s.toLowerCase();          // "ems-2026-01-01"

s.repeat(3);              // 重复 3 次（JDK 11+）
s.concat(" 结束");         // 拼接，等价于 +
```

三个替换方法的区别：

| 方法 | 参数 | 说明 |
| --- | --- | --- |
| `replace(CharSequence, CharSequence)` | 普通字符串 | 不解析正则，最安全 |
| `replaceAll(regex, replacement)` | 正则 | 替换串里的 `$` 和 `\` 要转义 |
| `replaceFirst(regex, replacement)` | 正则 | 只替换第一个 |

`substring(begin, end)` 含头不含尾，`substring(begin)` 到结尾；越界会抛异常。

## 8. 去空格：trim 与 strip

```java
String s = "  EMS  ";

s.trim();          // "EMS"，去掉首尾 <= U+0020 的字符
s.strip();         // "EMS"，去掉所有 Unicode 空白（JDK 11+）
s.stripLeading();  // 只去开头
s.stripTrailing(); // 只去结尾
```

`trim` 和 `strip` 的区别：

| | `trim()` | `strip()` |
| --- | --- | --- |
| 范围 | 只处理 ASCII 空格 | 处理所有 Unicode 空白（含全角空格） |
| 场景 | 英文输入 | 中文、全角空格 |

**坑**：全角空格 `　`（U+3000）`trim()` 去不掉，要用 `strip()`。

输入内容处理建议：

```java
String input = "  25.5  ";
double v = Double.parseDouble(input.strip());
```

## 9. 切分与拼接

### 9.1 split

```java
String line = "300.5,26.4,55.0";
String[] parts = line.split(",");
// ["300.5", "26.4", "55.0"]

"a,,b".split(",");        // ["a", "", "b"]
"a,b,,".split(",");       // ["a", "b"]  ← 末尾空串被丢弃！
"a,b,,".split(",", -1);   // ["a", "b", "", ""]  ← 保留空串
```

三个必须知道的点：

1. **参数是正则表达式**：`split(".")` 会得到空数组，因为 `.` 匹配任意字符，要写 `split("\\.")`；
2. **末尾空串默认丢弃**：需要保留时传第二个参数 `-1`；
3. 切分后每个元素自己 `trim()`，因为用户输入常带空格。

```java
String line = "300.5, 26.4, 55.0";
double temp = Double.parseDouble(line.split(",")[1].trim());
```

### 9.2 join

```java
List<String> list = List.of("A", "B", "C");
String joined = String.join(",", list);       // "A,B,C"

String[] arr = {"x", "y"};
String joined2 = String.join(" | ", arr);     // "x | y"
```

`String.join` 比循环拼接简洁，也没有多余逗号的问题。

## 10. 格式化输出

```java
double temp = 26.456;
String s = String.format("温度：%.1f℃，湿度：%d%%", temp, 55);
System.out.printf("%s = %.2f%n", "平均温度", 26.4);
```

常用占位符：

| 占位符 | 含义 | 例子 |
| --- | --- | --- |
| `%s` | 字符串 | `String.format("%s", obj)` |
| `%d` | 整数 | `String.format("%d", 42)` |
| `%f` | 小数（默认 6 位） | `String.format("%f", 3.14)` |
| `%.2f` | 保留 2 位小数 | `26.46` |
| `%5d` | 宽度 5，右对齐 | `"   42"` |
| `%-5d` | 宽度 5，左对齐 | `"42   "` |
| `%05d` | 补零 | `"00042"` |
| `%x` | 十六进制 | `"2a"` |
| `%%` | 百分号本身 | `"%"` |
| `%n` | 换行 | 跨平台换行 |

注意：`%f` 的精度会四舍五入；`String.format` 返回新字符串，`printf` 直接打印。

## 11. 数字与字符串互转

```java
// 字符串 → 数字
int n = Integer.parseInt("123");
long l = Long.parseLong("123456789");
double d = Double.parseDouble("26.4");
boolean b = Boolean.parseBoolean("true");

// 数字 → 字符串
String s1 = String.valueOf(42);
String s2 = Integer.toString(42);
String s3 = 42 + "";              // 也能用，但不推荐

// BigDecimal（精确小数）
BigDecimal big = new BigDecimal("0.1");
String s4 = big.toPlainString();  // 不用科学计数法
```

**坑**：

- `parseInt("abc")` 抛 `NumberFormatException`，转之前要校验或 try/catch；
- `parseInt(" 12 ")` 也会抛异常，先 `trim()`；
- `String.valueOf(null)` 返回 `"null"` 字符串，不是 null（如果传的是 `Object`）；
- 大整数超过 `int` 范围（约 21 亿）要用 `long`。

```java
// 安全转换
public static int toInt(String text, int defaultValue) {
    if (text == null || text.isBlank()) {
        return defaultValue;
    }
    try {
        return Integer.parseInt(text.trim());
    } catch (NumberFormatException e) {
        return defaultValue;
    }
}
```

## 12. 正则表达式入门

字符串的 `matches`、`split`、`replaceAll` 都用正则。

```java
"13800138000".matches("1\\d{10}");      // true，手机号
"EMS-01".matches("[A-Z]+-\\d+");        // true
"abc123".replaceAll("\\d", "#");        // "abc###"
"a1b2c3".replaceAll("[0-9]", "");       // "abc"
```

常用元字符：

| 符号 | 含义 |
| --- | --- |
| `.` | 任意一个字符 |
| `\d` | 数字（Java 里写 `\\d`） |
| `\w` | 字母、数字、下划线 |
| `\s` | 空白 |
| `*` `+` `?` | 0 次以上 / 1 次以上 / 0 或 1 次 |
| `{n}` `{n,m}` | 恰好 n 次 / n 到 m 次 |
| `[]` | 字符集合，`[abc]`、`[0-9]` |
| `^` `$` | 开头 / 结尾 |
| `()` | 分组 |
| `\\` | 转义（Java 字符串里也转义） |

两个坑：

1. **Java 里反斜杠要写两次**：正则 `\d` 在 Java 字符串里写 `"\\d"`；
2. **用户输入要当普通文本**：把用户输入拼进正则前用 `Pattern.quote(text)`，否则输入 `.*` 会匹配一切。

```java
String keyword = userInput;
boolean hit = text.matches(".*" + Pattern.quote(keyword) + ".*");
```

需要「找出一段并取分组」时用 `Pattern` + `Matcher`：

```java
Pattern p = Pattern.compile("(\\d+)\\.(\\d+)");
Matcher m = p.matcher("温度 26.45");
if (m.find()) {
    String whole = m.group(0);    // "26.45"
    String a = m.group(1);        // "26"
    String b = m.group(2);        // "45"
}
```

## 13. 编码与乱码

字符串本身是 Unicode，**乱码只发生在「转成字节」和「字节转回字符串」时编码不一致**。

```java
String s = "温度";

// 字符串 → 字节
byte[] utf8 = s.getBytes(StandardCharsets.UTF_8);
byte[] gbk = s.getBytes(Charset.forName("GBK"));

// 字节 → 字符串（编码必须与上面一致）
String back1 = new String(utf8, StandardCharsets.UTF_8);   // 正常
String back2 = new String(utf8, Charset.forName("GBK"));   // 乱码
```

乱码的三种典型：

| 现象 | 原因 |
| --- | --- |
| `æ¸©åº¦` | UTF-8 字节用 ISO-8859-1 解读 |
| `锟斤拷` | 编码反复转换，信息已丢失，救不回来 |
| `???` | 目标编码不支持中文（如 ASCII） |

规则：

- 读写文件、网络传输、数据库连接，**一律显式指定 UTF-8**；
- `new String(bytes)` 不带编码会用平台默认编码，换台机器就乱；
- 已经乱码的字符串，如果知道原编码，可以「用错误编码还原成字节，再用正确编码解码」，但前提是信息没丢失。

```java
// 补救：ISO-8859-1 误读的 UTF-8 字符串
byte[] raw = mojibake.getBytes(StandardCharsets.ISO_8859_1);
String fixed = new String(raw, StandardCharsets.UTF_8);
```

## 14. 性能：+ 与 StringBuilder

```java
// 循环里用 + 拼字符串：每次都创建新对象，1000 次就是 1000 个中间对象
String result = "";
for (int i = 0; i < 1000; i++) {
    result += i + ",";
}

// 正确做法：StringBuilder
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i).append(',');
}
String result2 = sb.toString();
```

对比：

| 方式 | 适用 | 线程安全 |
| --- | --- | --- |
| `+` | 少量、固定的拼接（编译器会自动优化成 `StringBuilder`） | 与线程无关 |
| `StringBuilder` | 循环、大量拼接 | 否 |
| `StringBuffer` | 多线程共享（很少用） | 是 |
| `String.join` | 集合/数组用分隔符连接 | 是 |

`StringBuilder` 常用方法：

```java
StringBuilder sb = new StringBuilder();
sb.append("温度：");
sb.append(26.4);
sb.append('℃');
sb.insert(0, "[");
sb.reverse();
sb.length();
sb.setLength(0);          // 清空，复用对象
String s = sb.toString();
```

一个循环里 `+=` 几百次，肉眼不容易看出卡；`+=` 几万次，程序明显变慢。

## 15. 中文、emoji 与 Unicode

```java
String s = "温度";
s.length();        // 2（两个中文，各 1 个 char）

String emoji = "😀";
emoji.length();              // 2！emoji 是代理对，占两个 char
emoji.codePointCount(0, emoji.length());   // 1，真正的「字符」数
```

| 概念 | 说明 |
| --- | --- |
| `char` | 16 位，UTF-16 的一个单元 |
| code point | 真正的 Unicode 字符编号 |
| 代理对 | 超过 U+FFFF 的字符用两个 char 表示 |
| 字素（grapheme） | 人眼看到的一个字符，可能由多个 code point 组成 |

处理建议：

- 判断「字符数」用 `codePointCount`，不要用 `length`；
- 截断用户输入（比如限 20 字）时，用 `codePoints` 或第三方库，直接 `substring` 可能切坏 emoji；
- 数据库列长度按字符算，emoji 可能占 2 个字符位置，注意字段长度。

```java
String input = "你好😀";
int chars = input.length();                                   // 4
int codePoints = input.codePointCount(0, input.length());     // 3
```

## 16. 实战：EMS 里的字符串处理

### 16.1 解析设备上报的一行数据

协议：`光照,温度,湿度`，如 `300.5,26.4,55.0`。

```java
public static double[] parseLine(String line) {
    if (line == null || line.isBlank()) {
        throw new IllegalArgumentException("空数据");
    }
    String[] parts = line.split(",");
    if (parts.length != 3) {
        throw new IllegalArgumentException("格式应为 光照,温度,湿度：" + line);
    }
    double[] values = new double[3];
    for (int i = 0; i < 3; i++) {
        values[i] = Double.parseDouble(parts[i].trim());
    }
    return values;
}
```

要点：判空、判断段数、每个字段 `trim`、数字转换抛异常由调用方处理。

### 16.2 拼 CSV 行（带转义）

```java
public static String toCsvRow(String... cells) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < cells.length; i++) {
        if (i > 0) {
            sb.append(',');
        }
        String cell = cells[i] == null ? "" : cells[i];
        if (cell.contains(",") || cell.contains("\"") || cell.contains("\n")) {
            sb.append('"').append(cell.replace("\"", "\"\"")).append('"');
        } else {
            sb.append(cell);
        }
    }
    return sb.toString();
}
```

### 16.3 格式化日志

```java
String log = String.format("%s  设备=%s  温度=%.1f℃",
        LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss")),
        deviceId, temp);
LogUtil.info(log);
```

### 16.4 拼 SQL 的正确姿势

```java
// 错误：字符串拼接，有 SQL 注入风险，还容易拼错引号
String sql = "SELECT * FROM ems WHERE device = '" + device + "'";

// 正确：用 PreparedStatement 占位符
String sql2 = "SELECT * FROM ems WHERE device = ?";
try (PreparedStatement ps = con.prepareStatement(sql2)) {
    ps.setString(1, device);
}
```

**规则：SQL 永远不要拼字符串**，哪怕参数是自己算出来的。

### 16.5 拼接 JSON 响应

```java
// 简单场景（数据里没有引号）
String json = String.format("{\"code\":0,\"temp\":%.1f}", temp);

// 有用户输入时，引号和反斜杠要转义
private static String escapeJson(String s) {
    return s.replace("\\", "\\\\").replace("\"", "\\\"");
}
```

复杂 JSON 请用 Gson，手拼容易漏转义。

## 17. 常见坑

| 坑 | 现象 | 正确做法 |
| --- | --- | --- |
| `==` 比较内容 | 有时候 true 有时候 false | 用 `equals` |
| `equals` 前半部分为 null | `NullPointerException` | `"常量".equals(变量)` |
| `split(".")` | 返回空数组 | `split("\\.")` |
| `split` 末尾空串丢失 | 少了几列 | `split(",", -1)` |
| `substring(a, b)` 边界 | 越界异常 | 含头不含尾，先判长度 |
| `indexOf` 结果判断 | `if (indexOf(x))` 编译不过 | 判断 `>= 0` |
| `trim` 去不掉全角空格 | 全角空格还在 | 用 `strip()` |
| 循环里 `+=` | 数据量一大就慢 | 用 `StringBuilder` |
| `parseInt` 不处理异常 | 输入非法直接崩 | try/catch 或先校验 |
| `new String(bytes)` | 换机器乱码 | 指定 `StandardCharsets.UTF_8` |
| 正则拼用户输入 | 用户输入 `.*` 匹配一切 | `Pattern.quote(...)` |
| `replaceAll` 替换串含 `$` | 报错或结果不对 | 用 `Matcher.quoteReplacement` |
| `String.valueOf(null)` | 得到 `"null"` | 先判空 |
| 用字符串拼 SQL | 注入风险 | `PreparedStatement` |
| emoji 截断 | 半个 emoji 或乱码 | 用 `codePointCount` 处理 |
