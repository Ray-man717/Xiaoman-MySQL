1. 先选对通信方式：TCP / UDP / HTTP

方式特点典型场景Java 相关类
TCP先连接再通信，可靠、有序、不丢传感器长连接上报、文件传输、控制指令Socket、ServerSocket
UDP不连接，发出去就不管，可能丢、可能乱序高频采样、局域网广播发现设备、心跳DatagramSocket、DatagramPacket
HTTP基于 TCP 的一问一答，通用、易调试对接 Web 接口、云平台、第三方服务HttpURLConnection、HttpClient

选型简单判断：

  • 数据不能丢、要能知道对方收到了 → TCP；
  • 数据量大、允许少量丢失、要低延迟 → UDP；
  • 对接现成的 Web 服务 / 云平台 / 手机 App → HTTP。

本项目最典型的场景是「采集设备定时把光照、温度、湿度发给服务器」，用 TCP + 按行协议 最简单，第 12 章就是它。

2. 地址与端口

一次 TCP 连接由「IP + 端口」唯一确定，通常写成 192.168.1.100:8888。

InetAddress local = InetAddress.getLocalHost();
System.out.println("本机名：" + local.getHostName());
System.out.println("本机 IP：" + local.getHostAddress());

InetAddress remote = InetAddress.getByName("192.168.2.51");
System.out.println("解析结果：" + remote.getHostAddress());

几个必须知道的概念：

概念说明
127.0.0.1 / localhost本机回环地址，只有自己这台机器能访问
局域网 IP（如 192.168.x.x）同一局域网内的其他电脑/设备可以通过它访问你
公网 IP外网访问需要，通常还要做端口映射
端口范围0 ~ 65535；1024 以下在 Linux/macOS 上需要管理员权限，日常用 8000 以上
端口被占用报 BindException: Address already in use，换端口或关掉占用的程序

查看本机 IP 和端口占用（Windows）：

ipconfig                                  # 看 IPv4 地址
netstat -ano | findstr :8888              # 看 8888 端口被谁占用
Test-NetConnection 127.0.0.1 -Port 8888   # 测端口通不通

关键点：服务端监听的是「本机所有网卡」还是「某个 IP」，决定了别人能不能连上。new ServerSocket(8888) 默认监听所有网卡；只想本机访问就绑 InetAddress.getLoopbackAddress()。

3. 最简单的 TCP 客户端

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.net.InetSocketAddress;
import java.net.Socket;
import java.nio.charset.StandardCharsets;

public class TcpClient {
    public static void main(String[] args) throws Exception {
        try (Socket socket = new Socket()) {
            // 1. 连接：带 3 秒超时，不加超时的话网络不通会卡很久
            socket.connect(new InetSocketAddress("127.0.0.1", 8888), 3000);
            socket.setSoTimeout(5000);      // 读超时：5 秒没数据就抛异常

            // 2. 拿输入输出流，按 UTF-8 包装成「一行一行」读写
            PrintWriter out = new PrintWriter(
                    new OutputStreamWriter(socket.getOutputStream(), StandardCharsets.UTF_8), true);
            BufferedReader in = new BufferedReader(
                    new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8));

            // 3. 发一行、收一行
            out.println("300.5,26.4,55.0");
            String reply = in.readLine();
            System.out.println("服务端回复：" + reply);
        }
        // 4. try-with-resources 自动关闭连接
    }
}

要点：

写法为什么
new Socket() + connect(addr, timeout)可以直接设连接超时，避免网络不通时长时间卡住
setSoTimeout(5000)设置读超时，避免对方不说话时一直阻塞
StandardCharsets.UTF_8两端编码必须一致，否则中文乱码
PrintWriter(..., true)第二个参数 true 表示自动 flush，println 后会真正发出去
try-with-resources自动关闭 socket，不用手写 finally { socket.close(); }

常见错误：只写了 new Socket("127.0.0.1", 8888) 而不设超时，网络不通时程序会「卡住」很长时间，用户体验极差。

4. 最简单的 TCP 服务端

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;

public class TcpServer {
    public static void main(String[] args) throws IOException {
        try (ServerSocket server = new ServerSocket(8888)) {
            System.out.println("服务已启动，监听 8888");
            while (true) {
                Socket socket = server.accept();          // 阻塞，直到有设备连上来
                System.out.println("设备接入：" + socket.getRemoteSocketAddress());
                handle(socket);                            // 单连接处理，简化版
            }
        }
    }

    private static void handle(Socket socket) {
        try (Socket s = socket;
             BufferedReader in = new BufferedReader(
                     new InputStreamReader(s.getInputStream(), StandardCharsets.UTF_8));
             PrintWriter out = new PrintWriter(
                     new OutputStreamWriter(s.getOutputStream(), StandardCharsets.UTF_8), true)) {

            String line;
            while ((line = in.readLine()) != null) {      // 对方关闭时返回 null
                System.out.println("收到：" + line);
                out.println("OK");                        // 回应一下，设备据此判断成功
            }
        } catch (IOException e) {
            System.out.println("连接异常：" + e.getMessage());
        }
    }
}

执行顺序：

  1. new ServerSocket(8888)：申请端口，端口被占用会直接抛 BindException；
  2. accept()：阻塞等待，有人连接才返回一个 Socket；
  3. 拿到 Socket 后，读写方式和客户端完全一样；
  4. readLine() 返回 null 表示对方正常关闭了连接。

这个版本一次只能服务一个设备（handle 是同步调用的），多设备要交给线程池，见第 7 章。

如果想限制 accept() 的等待时间：

server.setSoTimeout(30000);     // 30 秒没有新连接就抛 SocketTimeoutException

5. 收发数据与编码

5.1 按行协议（最常用）

约定「一行一条数据，\n 或 \r\n 结尾」：

// 发送
out.println("300.5,26.4,55.0");      // println 会自动加换行

// 接收
String line = in.readLine();          // 读到换行才返回

好处是简单、能用 telnet 手工测试；坏处是数据本身不能包含换行符。

5.2 中文乱码

乱码几乎只有一个原因：两端编码不一致（比如服务端 UTF-8、客户端 GBK，或者没指定编码用了系统默认）。

// 错误：依赖系统默认编码，换台机器就可能乱码
new InputStreamReader(socket.getInputStream())

// 正确：显式指定 UTF-8
new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8)

PrintWriter 也一样，用 new OutputStreamWriter(stream, StandardCharsets.UTF_8) 包装。

5.3 二进制数据

要发 int、double、文件字节时，用 DataInputStream / DataOutputStream：

// 发送
DataOutputStream out = new DataOutputStream(new BufferedOutputStream(socket.getOutputStream()));
out.writeInt(recordId);
out.writeDouble(26.4);
out.flush();                       // 缓冲流必须手动 flush

// 接收
DataInputStream in = new DataInputStream(socket.getInputStream());
int id = in.readInt();             // 阻塞直到读满 4 字节
double temp = in.readDouble();

注意 writeUTF / readUTF 适合短字符串（长度上限约 64KB），长数据不要用。

5.4 关闭顺序

// 推荐：先 flush 再关输出流，最后关 socket
out.flush();
socket.shutdownOutput();   // 告诉对方「我不会再发了」（可选）
socket.close();

用 try-with-resources 时这些都会自动处理，只要注意 PrintWriter 别忘了 flush。

6. 粘包与拆包（必须懂）

6.1 问题现象

TCP 是「字节流」，不是「消息流」。你 println 了 3 次，对方 readLine 可能一次读到 2 行、也可能半行：

  • 发送 A\n、B\n，接收端可能一次读到 A\nB\n（粘包）；
  • 发送一条很长的数据，接收端可能先读到前半段（拆包）。

6.2 三种解决办法

方案做法适用
分隔符每条数据以 \n 结尾，用 readLine 读文本协议，最简单
长度前缀先发 4 字节长度，再发内容二进制、内容可能含换行的场景
固定长度每条报文长度固定格式规整的二进制协议

用 readLine 时，只要两端都遵守「一行一条」，粘包问题就自动被解决了——这是选行协议的最大好处。

6.3 长度前缀写法

// 发送端
byte[] body = "300.5,26.4,55.0".getBytes(StandardCharsets.UTF_8);
DataOutputStream out = new DataOutputStream(new BufferedOutputStream(socket.getOutputStream()));
out.writeInt(body.length);     // 先写 4 字节长度
out.write(body);               // 再写内容
out.flush();

// 接收端
DataInputStream in = new DataInputStream(new BufferedInputStream(socket.getInputStream()));
int length = in.readInt();     // 阻塞直到 4 字节到齐
if (length < 0 || length > 1024 * 1024) {
    throw new IOException("长度异常：" + length);   // 防止恶意超大报文撑爆内存
}
byte[] buf = new byte[length];
in.readFully(buf);             // 保证读满 length 字节，读不满会抛 EOFException
String message = new String(buf, StandardCharsets.UTF_8);

关键点：用 readFully 而不是 read。read 只保证「至少读 1 字节」，可能读不满。

7. 多客户端并发

一台设备一个线程，是最直观的做法：

import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

public class ThreadPoolServer {
    private static final ExecutorService POOL = Executors.newFixedThreadPool(16);

    public static void main(String[] args) throws Exception {
        try (ServerSocket server = new ServerSocket(8888)) {
            System.out.println("服务已启动");
            while (true) {
                Socket socket = server.accept();
                POOL.submit(() -> handle(socket));     // 交给线程池，主线程继续 accept
            }
        }
    }

    private static void handle(Socket socket) {
        try (Socket s = socket) {
            // 每个连接独立的读写逻辑
        } catch (Exception e) {
            System.out.println("设备处理失败：" + e.getMessage());
        }
    }
}

要点：

问题处理
线程数无限增长用 newFixedThreadPool(16)，别用 newCachedThreadPool 又不限流
连接泄漏try-with-resources + 读写异常时及时关闭
设备卡住不发的连接setSoTimeout 让读操作超时退出
服务端忙不过来加队列、限流，或改用 NIO / Netty

Executors.newFixedThreadPool(16) 表示最多 16 个线程同时处理；再多设备就会排队。几百台设备的小系统足够用。

8. UDP 通信

UDP 不需要建立连接，适合「发一条就走」的场景。

8.1 接收端

import java.net.DatagramPacket;
import java.net.DatagramSocket;
import java.nio.charset.StandardCharsets;

public class UdpServer {
    public static void main(String[] args) throws Exception {
        try (DatagramSocket socket = new DatagramSocket(9999)) {   // 绑定端口
            byte[] buffer = new byte[1024];
            while (true) {
                DatagramPacket packet = new DatagramPacket(buffer, buffer.length);
                socket.receive(packet);                                // 阻塞等一条数据报

                String msg = new String(packet.getData(), 0, packet.getLength(),
                        StandardCharsets.UTF_8);
                String from = packet.getAddress().getHostAddress();
                int port = packet.getPort();
                System.out.println("来自 " + from + ":" + port + " → " + msg);
            }
        }
    }
}

注意 new String(packet.getData(), 0, packet.getLength(), UTF_8)：一定要用 getLength()，不能用整个 buffer 的长度，否则会带上一堆空字节。

8.2 发送端

try (DatagramSocket socket = new DatagramSocket()) {      // 不指定端口，系统随机分配
    byte[] data = "300.5,26.4,55.0".getBytes(StandardCharsets.UTF_8);
    DatagramPacket packet = new DatagramPacket(
            data, data.length,
            InetAddress.getByName("127.0.0.1"), 9999);
    socket.send(packet);
}

8.3 UDP 的几个坑

  • 单个数据报太大（超过约 1400 字节）容易被网络分片，丢失率会上升，建议一条几百字节以内；
  • 不保证顺序、可能重复，业务上要能做幂等（比如带设备号 + 时间戳去重）；
  • 广播要用 socket.setBroadcast(true)，且只在局域网内有效；
  • UDP 没有「连接」概念，服务端不知道对方什么时候「断开」。

9. HTTP 通信

9.1 HttpURLConnection（JDK 8 就有的写法）

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.net.HttpURLConnection;
import java.net.URL;
import java.nio.charset.StandardCharsets;

public class HttpGet {
    public static void main(String[] args) throws Exception {
        URL url = new URL("http://127.0.0.1:8080/api/ems/latest");
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        conn.setRequestMethod("GET");
        conn.setConnectTimeout(3000);
        conn.setReadTimeout(5000);
        conn.setRequestProperty("Accept", "application/json");

        int code = conn.getResponseCode();
        System.out.println("状态码：" + code);
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(conn.getInputStream(), StandardCharsets.UTF_8))) {
            StringBuilder sb = new StringBuilder();
            String line;
            while ((line = reader.readLine()) != null) {
                sb.append(line);
            }
            System.out.println(sb);
        }
    }
}

POST 提交 JSON：

HttpURLConnection conn = (HttpURLConnection) new URL(url).openConnection();
conn.setRequestMethod("POST");
conn.setDoOutput(true);
conn.setRequestProperty("Content-Type", "application/json; charset=UTF-8");
conn.setConnectTimeout(3000);
conn.setReadTimeout(5000);

String json = "{\"ali\":300.5,\"temp\":26.4,\"humidity\":55.0}";
try (OutputStream os = conn.getOutputStream()) {
    os.write(json.getBytes(StandardCharsets.UTF_8));
}

int code = conn.getResponseCode();
// 4xx / 5xx 要用 getErrorStream() 读错误信息，getInputStream() 会抛异常

9.2 HttpClient（JDK 11+，推荐）

项目是 JDK 17，直接用它，代码短很多：

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import java.time.Duration;

public class HttpClientDemo {
    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newBuilder()
                .connectTimeout(Duration.ofSeconds(3))
                .build();

        HttpRequest getReq = HttpRequest.newBuilder()
                .uri(URI.create("http://127.0.0.1:8080/api/ems/latest"))
                .timeout(Duration.ofSeconds(5))
                .GET()
                .build();

        HttpResponse<String> resp = client.send(getReq, HttpResponse.BodyHandlers.ofString(StandardCharsets.UTF_8));
        System.out.println(resp.statusCode());
        System.out.println(resp.body());

        // POST JSON
        String json = "{\"ali\":300.5,\"temp\":26.4,\"humidity\":55.0}";
        HttpRequest postReq = HttpRequest.newBuilder()
                .uri(URI.create("http://127.0.0.1:8080/api/ems"))
                .header("Content-Type", "application/json; charset=UTF-8")
                .timeout(Duration.ofSeconds(5))
                .POST(HttpRequest.BodyPublishers.ofString(json, StandardCharsets.UTF_8))
                .build();

        HttpResponse<String> postResp = client.send(postReq,
                HttpResponse.BodyHandlers.ofString(StandardCharsets.UTF_8));
        System.out.println("POST 状态：" + postResp.statusCode() + " " + postResp.body());
    }
}

异步发送（不阻塞当前线程）：

client.sendAsync(postReq, HttpResponse.BodyHandlers.ofString())
      .thenAccept(r -> System.out.println("异步结果：" + r.statusCode()));

10. JSON：没有第三方库怎么办

JDK 没有内置 JSON 解析。三种选择：

方式说明
引入依赖gson（约 280KB）或 jackson-databind，功能完整，推荐
手写解析格式固定的小报文可以，超过两层嵌套就别自己写
换格式内部协议用「逗号分隔」或「key=value」，根本不用 JSON

Gson 引入方式（放 jar 到项目里，加进 classpath）：

java -cp "out;mysql-connector-java-5.1.49.jar;gson-2.10.1.jar" com.github.rayman717.net.Main
// 用 Gson
Gson gson = new Gson();
EmsRecord record = gson.fromJson(json, EmsRecord.class);
String out = gson.toJson(record);

不引依赖时的极简取值（只适合 {"key": 123}、{"key": "abc"} 这种平铺结构）：

/** 从平铺 JSON 里取一个 key 的值，取不到返回 null */
static String jsonValue(String json, String key) {
    String pattern = "\"" + key + "\"";
    int i = json.indexOf(pattern);
    if (i < 0) {
        return null;
    }
    int colon = json.indexOf(':', i + pattern.length());
    if (colon < 0) {
        return null;
    }
    int start = colon + 1;
    while (start < json.length() && Character.isWhitespace(json.charAt(start))) {
        start++;
    }
    if (start >= json.length()) {
        return null;
    }
    if (json.charAt(start) == '"') {
        int end = json.indexOf('"', start + 1);
        return end < 0 ? null : json.substring(start + 1, end);
    }
    int end = start;
    while (end < json.length() && ",}".indexOf(json.charAt(end)) < 0) {
        end++;
    }
    return json.substring(start, end).trim();
}

// 用法
String temp = jsonValue("{\"temp\":26.4,\"humidity\":55}", "temp");   // "26.4"

只用于「格式固定、不嵌套、不做通用解析」的场景。一旦报文结构会变，直接上 Gson，别手写。

11. 网络、数据库、界面怎么串起来

EMS 系统里数据是这样流动的：

采集设备（Socket 客户端）
        │  TCP，每 2 秒一条 "光照,温度,湿度"
        ▼
服务端（ServerSocket 接收）
        │  JDBC 插入
        ▼
MySQL（ems 表）
        │  JDBC 查询
        ▼
Swing 监控界面（表格展示，见《Swing 使用手册》）

两条硬规则：

  1. 网络读写是阻塞的，不能在 Swing 的 EDT 里做，否则界面卡死——用 SwingWorker 或后台线程；
  2. 界面更新必须在 EDT 上做，后台线程拿到数据后 SwingUtilities.invokeLater(...) 回界面。

界面里定时从服务端拉数据的骨架：

// 每 5 秒拉一次，SwingWorker 在后台做网络请求，done() 回 EDT 更新表格
Timer timer = new Timer(5000, e -> new SwingWorker<List<Object[]>, Void>() {
    @Override
    protected List<Object[]> doInBackground() throws Exception {
        HttpResponse<String> resp = httpClient.send(request, HttpResponse.BodyHandlers.ofString());
        return parseTable(resp.body());
    }

    @Override
    protected void done() {
        try {
            List<Object[]> rows = get();
            model.setRowCount(0);
            for (Object[] row : rows) {
                model.addRow(row);
            }
        } catch (Exception ex) {
            statusLabel.setText("拉取失败：" + ex.getCause());
        }
    }
}.execute());
timer.start();

更直接的方式是界面直接用 JDBC 查库（见《Swing 使用手册》第 12 章），网络只在「设备和服务器之间」需要。

12. 实战：EMS 设备数据上报系统

12.1 协议约定

项目约定
传输TCP，端口 8888
格式一行一条，UTF-8，逗号分隔：光照,温度,湿度
示例300.5,26.4,55.0
成功回复OK
失败回复ERR 原因，如 ERR 格式错误

12.2 服务端（EmsDataServer.java）

package com.github.rayman717.net;

import com.github.rayman717.entity.DbConfig;
import com.github.rayman717.util.ConfigManager;

import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.SQLException;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

/**
 * EMS 数据接收服务端。
 * <p>
 * 设备通过 TCP 上报一行 "光照,温度,湿度"，服务端解析后写入 ems 表，并回复 OK / ERR。
 */
public class EmsDataServer {

    private static final int PORT = 8888;
    /** 最多 16 台设备同时处理，更多会排队 */
    private static final ExecutorService POOL = Executors.newFixedThreadPool(16);

    public static void main(String[] args) throws IOException {
        ConfigManager.initConfig();                       // 读取 config.properties

        try (ServerSocket server = new ServerSocket(PORT)) {
            System.out.println("EMS 数据服务已启动，监听端口 " + PORT);
            while (true) {
                Socket socket = server.accept();
                System.out.println("设备接入：" + socket.getRemoteSocketAddress());
                POOL.submit(() -> handle(socket));         // 一个连接一个任务
            }
        }
    }

    /** 处理一台设备的连接：按行读取，逐条入库 */
    private static void handle(Socket socket) {
        try (Socket s = socket;
             BufferedReader in = new BufferedReader(
                     new InputStreamReader(s.getInputStream(), StandardCharsets.UTF_8));
             PrintWriter out = new PrintWriter(
                     new OutputStreamWriter(s.getOutputStream(), StandardCharsets.UTF_8), true)) {

            String line;
            while ((line = in.readLine()) != null) {        // 设备断开时返回 null
                if (line.trim().isEmpty()) {
                    continue;
                }
                try {
                    saveRecord(line);
                    out.println("OK");
                } catch (Exception ex) {
                    out.println("ERR " + ex.getMessage());  // 告诉设备这条失败了
                }
            }
            System.out.println("设备断开：" + s.getRemoteSocketAddress());
        } catch (IOException e) {
            System.out.println("连接异常：" + e.getMessage());
        }
    }

    /** 解析一行数据并写入 ems 表 */
    private static void saveRecord(String line) throws SQLException {
        String[] parts = line.split(",");
        if (parts.length != 3) {
            throw new IllegalArgumentException("格式应为 光照,温度,湿度");
        }

        double ali;
        double temp;
        double humidity;
        try {
            ali = Double.parseDouble(parts[0].trim());
            temp = Double.parseDouble(parts[1].trim());
            humidity = Double.parseDouble(parts[2].trim());
        } catch (NumberFormatException e) {
            throw new IllegalArgumentException("数值格式错误");
        }

        DbConfig config = ConfigManager.getDbConfig();
        String url = "jdbc:mysql://" + config.ip + ":3306/" + config.dbName
                + "?useSSL=false&characterEncoding=utf8";
        String sql = "INSERT INTO ems (ALI, Temp, Humidity) VALUES (?, ?, ?)";

        // 每次上报开一个连接，教学够用；生产环境应换成连接池
        try (Connection con = DriverManager.getConnection(url, config.user, config.password);
             PreparedStatement ps = con.prepareStatement(sql)) {
            ps.setDouble(1, ali);
            ps.setDouble(2, temp);
            ps.setDouble(3, humidity);
            ps.executeUpdate();
        }
    }
}

12.3 设备模拟器（EmsDeviceClient.java）

package com.github.rayman717.net;

import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.PrintWriter;
import java.net.InetSocketAddress;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.Random;

/**
 * 模拟一台 EMS 采集设备：每 2 秒上报一条随机数据，并打印服务端回复。
 */
public class EmsDeviceClient {

    public static void main(String[] args) throws Exception {
        String host = "127.0.0.1";     // 服务端 IP，跨电脑时改成服务端的局域网 IP
        int port = 8888;
        Random random = new Random();

        try (Socket socket = new Socket()) {
            socket.connect(new InetSocketAddress(host, port), 3000);
            socket.setSoTimeout(5000);

            PrintWriter out = new PrintWriter(
                    new OutputStreamWriter(socket.getOutputStream(), StandardCharsets.UTF_8), true);
            BufferedReader in = new BufferedReader(
                    new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8));

            while (true) {
                double ali = 200 + random.nextInt(200);
                double temp = 20 + random.nextInt(150) / 10.0;
                double humidity = 40 + random.nextInt(400) / 10.0;

                String line = String.format("%.1f,%.1f,%.1f", ali, temp, humidity);
                out.println(line);
                String reply = in.readLine();
                System.out.println("上报：" + line + "  →  " + reply);

                Thread.sleep(2000);
            }
        }
    }
}

13. 常见问题与报错

现象原因解决
ConnectException: Connection refused服务端没启动、端口写错、防火墙拦截确认服务端在跑，Test-NetConnection 测端口
SocketTimeoutException: connect timed out网络不通或对端 IP 错检查 IP、ping 一下、确认同一网段
BindException: Address already in use端口被占用netstat -ano 找占用进程，或换端口
BindException: Permission denied用了 1024 以下端口换 8000 以上的端口
UnknownHostException主机名/IP 写错，或 DNS 解析失败用 IP 测试
读不到数据、一直阻塞对端没发、没换行、没 flush检查 println 与 flush，设 setSoTimeout
readLine 返回 null对方关闭了连接正常结束本次会话
Connection reset对方异常断开（强杀进程）捕获异常后清理连接，别让线程泄漏
中文乱码两端编码不一致统一 StandardCharsets.UTF_8
一次收到半条 / 两条数据粘包拆包用行协议或长度前缀，见第 6 章
两台电脑连不上服务端监听回环地址、防火墙、IP 错绑 0.0.0.0（默认），Windows 允许防火墙，用局域网 IP
ClassNotFoundException: com.mysql.jdbc.Driver运行缺少驱动 jar-cp 加上 mysql-connector-java-5.1.49.jar
界面卡死在 EDT 里做网络或数据库操作交给后台线程 / SwingWorker
UDP 收不到没绑定端口、防火墙、数据报太大检查绑定端口与大小
java.net.SocketException: Too many open files连接没关闭，文件句柄泄漏全部用 try-with-resources

排查三步法：

# 1. 服务在不在？
netstat -ano | findstr :8888
# 2. 端口通不通？
Test-NetConnection 127.0.0.1 -Port 8888
# 3. 自己有没监听？
Get-NetTCPConnection -LocalPort 8888 -ErrorAction SilentlyContinue
